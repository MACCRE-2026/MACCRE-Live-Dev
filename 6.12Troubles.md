Why it's stuck at "fan-out registered, never truly parallel"
UniversalSwarmWorker.execute_cycle() does one thing: claim one task row, run it fully (LLM call, tools, everything), return. The while True: worker.execute_cycle() loop in flow_engine.py calls this from a single thread. When CTRL_SCATTER fires, it correctly inserts 8 tagged rows into task_queue — but the same lone loop drains them one at a time. Every planning doc from v1 through Era 3 names the fix (ThreadPoolExecutor(max_workers=8)) and defers it to "Phase 6.12," which is why you keep seeing that ghost.

I also found the four specific things that would silently break if you just wrapped execute_cycle() in threads today without fixing them first:

sys.stdout/sys.stderr get globally reassigned per task (_FileTee, swarm_worker.py ~L570-580) to route agent output to a per-node log file. That's a process-wide mutation — with real threads, two agents running concurrently would stomp each other's stdout redirection and logs would interleave into the wrong files.
AGENT_ID is a module-level constant (f"universal_node_{os.getpid()}") — every thread would report the identical worker ID, making it impossible to tell which thread did what in logs/telemetry.
CacheManager does an unlocked read-modify-write of active_caches.json — two agents hitting the >120k-char context-cache path at the same instant can corrupt or clobber each other's cache registry entry.
TopologyVisualizer.set_active_node() forcibly demotes whatever was previously active the moment a new node goes active — a hardcoded single-active-node model. Even with a perfect concurrent backend, it physically cannot show 2+ nodes lit up at once without this changing.
None of these are hard fixes, but skipping any of them turns "8 parallel agents" into "8 agents with corrupted logs and a visualizer that lies about what's running."

def resolve_node_appendix(mode: str, current_tether_id: str, topology_snapshot: list[dict]) -> str:
    if mode == "ALL":
        lines = ["## Topology Context (All Nodes)\n"]
        for node in topology_snapshot:
            lines.append(f"- {node['node_id']} (tether:{node['tether_id']})")
    else:  # Scoped
        lines = ["## Topology Context (Your Flow Line)\n"]
        tether_prefix = current_tether_id.split(".")[0]
        for node in topology_snapshot:
            if node['tether_id'].startswith(tether_prefix):
                lines.append(f"- {node['node_id']} (tether:{node['tether_id']})")
    return "\n".join(lines)
