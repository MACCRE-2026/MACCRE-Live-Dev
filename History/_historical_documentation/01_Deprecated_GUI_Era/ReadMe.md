**Version:** Phase 19 — Sovereign Spreadsheet Intake, Drive Inbox, & Cross-Device Database Sync | April 2026

## 1. The Core Thesis: "Sovereign Edge Intelligence"
MACCREv2 is a headless, multi-agent swarm engine that runs wherever Python runs — Windows laptop, Samsung S25, or any future device. It processes creative and data payloads through configurable agent pipelines and produces written, audio, and video artifacts with full cost and cognitive transparency.

We achieve enterprise-grade multi-agent capabilities at consumer subscription cost parity by combining:
- **Google Gemini Cloud API** for deep reasoning, structured extraction, TTS, and image generation
- **Local Gemma (via Ollama)** for zero-cost edge routing, tagging, and summarization
- **Local FFmpeg + ChromaDB** for sovereign media assembly and semantic memory
- **Google Drive** as the shared state bus between devices — no central server required

The Strangler Fig principle governs every external dependency: interfaces before implementations, cloud before local, escalate as the product earns it.

## 2. Law of Cognitive Physics: The Diamond Loop
Never mix visionary generation with deterministic parsing. All reasoning is split-temperature:

- **The Generator (Temp 1.0):** Creative ideation, swarm architecture design, narrative writing. Maximum cognitive entropy. `gemini-2.5-pro` or `gemma3` depending on context size.
- **The Critic / Synthesizer (Temp 0.1):** Structured extraction into Pydantic `BaseModel` via `response_schema`. Zero hallucination risk — the schema is physically enforced.
- **The Rule:** Generator output NEVER touches the Datacenter or ChromaDB until it has passed through a Critic node constrained by a typed schema. Regex parsing is permanently forbidden for structured data.

The Diamond Loop is the engine behind `design_swarm()` and `fill_swarm_sheet()`: Leg 1 is a high-temp ideation call; Leg 2 is a cold extractor that writes a verified `SwarmDesign(BaseModel)` to disk. Neither leg can contaminate the other.

## 3. Law of Data Sovereignty: The 5-Tier Datacenter
MACCREv2 maintains absolute data sovereignty through a strict 5-tier directory tree at `B:\MACCREv2\__DATACENTER`:

| Tier | Path | Purpose | Access |
|---|---|---|---|
| `01_Raw_Source` | `01_Raw_Source/` | Untouched ingest — raw docs, conversations, payload text | RAG read-only |
| `02_Dynamic_Context` | `02_Dynamic_Context/` | Agent ROM cartridges (`.json`), topology, pipeline config | System read/write |
| `03_Agent_Ledgers` | `03_Agent_Ledgers/` | Strict JSON thought audits per swarm node | Append-only |
| `04_Code_Artifacts` | `04_Code_Artifacts/` | Generated code, manifests, spreadsheet specs | Output write |
| `05_Rendered_Media` | `05_Rendered_Media/` | TTS audio, FFmpeg clips, stitched MP4 output | Render write |

Each project gets its own silo: `__DATACENTER/<PROJECT_NAME>/` with the full 5-tier tree. A `GLOBAL` silo holds work not scoped to a specific project. The `MACCRE_ACTIVE_PROJECT` environment variable routes all tool calls to the correct silo.

**Routing Contract:**
- RAG/ingestion reads ONLY from `01` and `02`.
- Output generation writes ONLY to `04` and `05`.
- Thought audits write ONLY to `03`.
- No agent reads its own output as new input (no ouroboros ingestion loops).

## 4. Law of Project Completeness: The Configuration Workbook
Every project silo created by `initialize_workspace()` contains a **blank `MACCRE_Swarm_Request.xlsx`** in its root. This workbook is the canonical specification artifact for that project — it is human-readable, machine-parseable, and portable.

**The workbook is the project.** It replaces the following legacy files:
- `agent_roster.csv` → AGENTS sheet
- `topology.csv` → TOPOLOGY sheet
- `project_schema.json` metadata → SWARM_REQUEST sheet
- `pipeline.json` render config → PIPELINE_CONFIG sheet
- `memory_config.json` RAG config → MEMORY_CONFIG sheet

The base template is generated by `scripts/generate_template.py` and lives at `B:\MACCREv2\templates\MACCRE_Swarm_Request.xlsx`. When Nexus detects a missing workbook in a project root, it regenerates one automatically.

## 5. Law of Sovereign Intake: The Drive Inbox Daemon
Swarm execution is triggered by dropping a configured workbook into the Google Drive inbox — not by typing terminal commands (though manual terminal execution is always available).

**APPROVED Trigger Pattern:** Any `.xlsx` file renamed or saved with `_APPROVED` appended to its filename anywhere inside `__DATACENTER` triggers the watcher daemon. Approval is always a deliberate human action (or a PIN-gated Nexus action) — never autonomous.

**Watcher Daemon (`python maccre.py watch`):**
1. Detects `*_APPROVED.xlsx` in `__DATACENTER` (recursive, OS-level `inotify`/`ReadDirectoryChanges`)
2. 4-second settle wait (Drive sync completion)
3. Parses workbook via `sheet_parser.py` → verified `ParsedWorkbook`
4. Materialises workspace: agents, ROM cartridges, topology
5. Writes inline payload to `01_Raw_Source/input.md` if present
6. Ignites and executes swarm — fully blocking per-job
7. Renames file to `.processed` to prevent re-trigger
8. Emits Windows toast notification on completion
9. All events logged to `GLOBAL/03_Agent_Ledgers/watcher_telemetry.json`

**Swarm execution is device-bound.** Workbooks designed on a device execute on that device. Cross-device coordination is handled by database nugget sync, not by routing swarm jobs across the network.

## 6. Law of Cross-Device Sovereignty: Database Nuggets
Every MACCRE instance on every device maintains its own local databases (`thoughts.db`, `swarm_queue.db`, `chroma_db/`). After each swarm completion, it exports a compressed snapshot — a **database nugget** — to Google Drive.

**Export (automatic, post-swarm):**
- ChromaDB collections → `__DataCenter/<PROJECT>/_nuggets/<DEVICE_ID>_vectors.json`
- SQLite thoughts/ledger → `__DataCenter/<PROJECT>/_nuggets/<DEVICE_ID>_thoughts.db.gz`
- Work products (MP4, markdown, manifests) → `__DataCenter/<PROJECT>/05_Rendered_Media/`

**Import (on-demand, new device):**
- `python maccre.py sync --project <PROJECT>` fetches all nuggets for a project
- Merges foreign vectors into local ChromaDB via `import_foreign_vectors`
- Replays ledger entries into local `thoughts.db`
- Device immediately has the full cognitive history of the project

**The result:** Any device can pick up any project where any other device left it, with the complete semantic memory and thought audit trail. Work products are always available via the Google Drive junction. No custom sync server required.

## 7. Law of Swarm Dynamics: The Scatter-Gather Engine
- Swarms use a SQLite-backed Scatter-Gather state machine (`local_broker.py`) with `UNIQUE(job_id, current_node)` idempotent routing and `BEGIN EXCLUSIVE` worker serialization — eliminating TOCTOU race conditions at the C engine level.
- Worker processes are ephemeral daemons (`swarm_worker.py`). They spawn, process exactly one job, and exit. No zombie accumulation.
- The topology DAG is defined in the TOPOLOGY sheet of the project workbook. Each node specifies: `NODE_ID`, `AGENT_NAME`, `AUTO_TOOL`, `NEXT_NODE`, `INSTRUCTION_OVERRIDE`, and optional per-node compute overrides.

## 8. Law of Scalability: The Strangler Fig Interface
Every external I/O operation is masked behind an `abc.ABC` Python interface. Agents never know what backend they are talking to.

- **Current Tier:** Local ChromaDB (Vector), Google Drive (State), Gemini API (Inference), FFmpeg (Render), Ollama (Edge).
- **Enterprise Escalation:** Interfaces swap to Google Cloud Pub/Sub, AlloyDB pgvector, Vertex AI Search without rewriting agent logic.

## 9. Law of Edge Economics: Compute Routing
Compute is pushed to the absolute edge whenever practical:

| Tier | Model | Cost | Use Case |
|---|---|---|---|
| **Local Gemma 3** | `gemma3:9b` via Ollama | $0.00 | Routing, tagging, summarization, offline |
| **Gemini Flash** | `gemini-2.5-flash` | ~$0.001/1k tok | Most agent nodes, RAG queries |
| **Gemini Pro** | `gemini-2.5-pro` | ~$0.01/1k tok | Diamond Loop critic, deep reasoning, Thinking mode |
| **Imagen 3** | `imagen-3.0-generate-001` | $0.03/image | Scene visual generation |
| **Gemini TTS** | `gemini-2.5-pro-preview-tts` | $0.05/1k chars | Podcast audio synthesis |

`compute_tier` is configurable per-agent and per-node in the workbook: `cloud`, `local`, or `hybrid` (try local first, fall back to cloud on timeout).

FinOps receipts are captured on every cloud inference call and written to `system_logs.db`. `estimate_manifest_cost()` provides pre-flight estimates before any render job.

## 10. Law of Self-Healing Infrastructure
- **Epoch Drift Protocol:** `CloudMediaPipeline.generate_image()` catches `404 NOT_FOUND`, auto-selects the newest available Imagen model from `client.models.list()`, persists the resolved name.
- **Retry:** Image generation uses exponential backoff with `retry-after` parsing on 429s.
- **FFmpeg Auto-Discovery:** `shutil.which("ffmpeg")` first, then WinGet install glob fallback.
- **JSON Repair Loop:** When the Diamond Loop Critic receives a truncated JSON response, `design_tools.py` runs a repair loop using `gemini-2.5-flash` to reconstruct the schema before failing.

## 11. OmniBuilder CI/CD Pipeline
All development is governed by the `omni` CLI:

| Command | Function |
|---|---|
| `omni qa .` | Ruff lint + Pyright type-check (zero tolerance) |
| `omni build .` | Purge cache → QA → PyInstaller compile |
| `omni clean` | Hunt zombie processes, purge `__pycache__` |
| `omni run` | Execute local entry point cleanly |

**Non-negotiable standards:**
- Every signature, return type, and class attribute must have explicit Python 3.11+ type hints.
- Zero unused imports. No wildcard imports. Max line length 120.
- All file handlers, WebSockets, and subprocess calls wrapped in `try/finally`.
- `print()` forbidden for telemetry. All loggers output strict JSON.
- `from __future__ import annotations` (PEP 563) BANNED from all tool files. SDK function-calling schema builder requires real type objects, not strings.

## 12. Security: Polyglot Sovereign Credential Vault
API keys are never stored in plaintext `.env` files:
- **Windows Credential Manager** (`advapi32.dll` via `ctypes`) — pure stdlib, no third-party deps.
- **Polyglot Key Ingestor:** `python maccre.py config set-key <key>` fingerprints the key via regex (`sk-proj` = OpenAI, `sk-ant` = Anthropic, `AIza` = Gemini) and routes to the correct DPAPI namespace.
- **Conditional Release (PIN Elevation):** Sensitive file operations (permanent deletion, cross-project writes) require a session PIN established at startup. The PIN is never stored — it exists only in memory for the duration of the session.

## 13. Law of Agent Casting: The Central Library
Frequently reused agents are stored in a **Central Casting Library** at `__DATACENTER/GLOBAL/04_Code_Artifacts/MACCRE_Agent_Library.xlsx`. This file uses the identical schema as the AGENTS sheet of any project workbook — rows can be copy-pasted directly into any project. Nexus can save any designed agent to the library (`save_agent_to_library`) and inject saved agents into active projects (`inject_agent_from_library`).

## 14. Law of SDK Type Integrity
All tool files registered with the Google GenAI SDK for automatic function calling MUST NOT use `from __future__ import annotations` (PEP 563). Python 3.11 native type syntax (`list[T]`, `dict[K,V]`, `X | None`) is used throughout. See the complete rationale in `maccrev2_tool_guide.md`.

## 15. Law of Headless Sovereignty (The Decapitation Protocol — Permanent)
MACCRE is a headless pipeline engine. It operates like `ffmpeg` or `git`: sovereign, modular, terminal-first. The Flet GUI (Phases 9–12) has been permanently archived to `_archive/legacy_gui/`.

**The Nexus Terminal UI (`maccre.py chat`) is NOT a GUI.** It is a rich, scrollable terminal session (Textual TUI) that implements a multi-turn conversational loop with full tool-calling capability. It is the primary human interface. It runs inside any terminal without a display server, window manager, or GUI runtime dependency.

**If a visual GUI is ever needed (Phase 25+):** It must be a completely separate microservice reading SQLite WAL as a passive consumer. It must never own MACCRE state.

**Entry Points (canonical):**
```bash
# Global Nexus Agent — Conversational Orchestrator
python maccre.py chat

# Drive Inbox Watcher Daemon
python maccre.py watch

# Inject a payload and run headlessly
python maccre.py ignite <payload.md> --node NODE_01_INGEST

# Check swarm queue status
python maccre.py status

# Merge session memory to project
python maccre.py canonize --project <NAME> --session <SESSION_ID>

# Import API key
python maccre.py config set-key <key>
```
