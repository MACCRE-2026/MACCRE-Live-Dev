# EXO-GANS User Scripts

This directory houses the standalone ingestion, scraping, and database-generation scripts imported from the MACCREv2 architecture, alongside the Gemini Hoarder web-scraping ecosystem. These tools form the pipeline that converts external human conversations, AI Studio sessions, and Antigravity logs into the sovereign Markdown/Vector format required by the EXO-GANS `01_Raw_Source` datacenter.

## 1. Tool Scope & Usability

### `AIstudioConvoScraper.ps1` & `delta_scraper.ps1`
* **Purpose**: PowerShell scripts designed to scrape conversation histories from Google AI Studio. 
* **Usability**: Highly functional. These scripts handle the extraction of raw JSON/Text from web backups and transform them into flat files.

### `export_antigravity_history.py`
* **Purpose**: Parses the highly-structured, internal `.jsonl` system logs generated by the Antigravity developer agent. It reconstructs the conversation timeline, extracts tool calls, and pulls down generated artifacts into human-readable Markdown.
* **Usability**: Critical. This ensures the Nexus agent can snapshot and archive the dev-agent's cognitive state or workflow steps for historical provenance.

### `run_antigravity_ingest.py`
* **Purpose**: The execution wrapper for the core MapReduce ingestion pipeline. It reads raw Markdown files from the datacenter, chunks them, and vectorizes them into the Triune SQLite databases.
* **Usability**: Critical. This is the command-line trigger for the `antigravity_ingest` module.

### `bulk_ingest.py`
* **Purpose**: A sweeping utility that iterates over every sub-directory in the `__DATACENTER` and triggers a vector ingestion for each project silo.
* **Usability**: Highly functional. Ideal for completely resetting the environment or updating the vector DBs after a massive multi-project data dump.

### `Gemini_Hoarder_Ecosystem/`
* **Purpose**: A comprehensive web-scraping suite ("Gemini Hoarder - God Mode") built to extract chat histories directly from the Google Gemini web UI. It utilizes a Chrome Extension with aggressive DOM scanning (shadow DOM penetration) to iteratively click through history and download chats as Turndown Markdown.
* **Usability**: Specialized / Highly functional. It includes several Python scripts (`godmode_fix.py`, `unlimited_mode.py`, etc.) that act as hot-patches to re-configure the extension's behavior (e.g., bypassing limits, granting `all_frames` permissions).

## 2. EXO-GANS Integration Protocol

**Attention Next Dev-Agent:**
The objective for EXO-GANS is to run a completely deterministic, text-only pipeline orchestrated by "The Nexus Agent." The Nexus Agent operates via a multi-window-plex UI and does not write code—it only invokes tools and generates workbooks. 

To give the Nexus Agent the ability to autonomously update its own knowledge bases, you must convert these standalone scripts into native EXO-GANS tools:

1. **Create the Tool Schemas:**
   Define explicit Python functions in the `maccre_core/tools/` registry for each script (e.g., `def trigger_ai_studio_scrape(path: str) -> str:`).
   
2. **Wrap Subprocesses Safely:**
   Use standard Python `subprocess.run()` calls inside these tool wrappers to execute the powershell scripts (`.ps1`) or python wrappers. Ensure stdout/stderr are captured and returned cleanly to the LLM context so the Nexus Agent knows if an ingestion failed or succeeded.

3. **Strict Datacenter Routing:**
   Hardcode the tool wrappers so that all data scraped by the `.ps1` files or downloaded by the Gemini Hoarder extension is forced directly into `get_datacenter_path("01_Raw_Source")`. The Nexus agent must not be able to dump scraped data anywhere else in the file system.

4. **UI Event Emission (Tunable Ephemerality):**
   When `bulk_ingest.py` or `run_antigravity_ingest.py` finishes executing, the tool must fire a ZMQ event or update a state flag so the multi-window-plex UI can refresh the user's active context windows automatically.
