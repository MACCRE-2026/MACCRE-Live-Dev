# Contributing to EXO_GANS

Thank you for your interest in MAACRE! 

This project is currently in **active solo development**. It is highly opinionated, structured around a specific deterministic orchestration philosophy, and serves as my primary engineering portfolio and daily workspace.

Because of this, the contribution model is strict.

## Bug Reports and Issues

**Yes, please!**
If you find a bug, a memory leak in the Omni CI/CD pipeline, or a logical flaw in the graph routing, please open an issue. 

If you want to discuss the architecture, suggest a new `CTRL_` primitive, or debate the merits of strict deterministic routing vs non-deterministic agents, open an issue! I built this to learn and collaborate.

## Pull Requests

**Please do not submit unsolicited Pull Requests.**

Because the architecture is highly opinionated and constantly evolving in my local environment, large unsolicited PRs are likely to cause merge conflicts or violate the underlying doctrine. 

If you want to contribute code:
1. Open an Issue first.
2. Propose your change and the architectural reasoning behind it.
3. If we agree on the direction, you can submit the PR.

## Code of Conduct

Be a professional builder. Respect the codebase, respect the time of others, and focus on the engineering.
